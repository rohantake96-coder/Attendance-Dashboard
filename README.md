# Class Attendance Trend Dashboard

## Description
A Python-based dashboard that analyzes class attendance data and visualizes monthly attendance trends using Pandas and Matplotlib.

## Features
- Monthly attendance bar chart
- Attendance trend line graph
- Attendance distribution pie chart
- Average, highest, and lowest attendance calculations
- Summary dashboard with multiple charts

## Technologies Used
- Python
- Pandas
- Matplotlib

## Installation

Install the required libraries:

```bash
pip install pandas matplotlib
```

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run the Python file:

```bash
python attendance_dashboard.py
```

4. The Class Attendance Trend Dashboard will appear.

## Sample Data
The project currently uses sample monthly attendance percentages. You can modify the data in the Python code to analyze your own attendance records.
